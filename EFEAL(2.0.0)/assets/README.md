# EFEAI Assets Klasörü

Bu klasör EFEAI'nin görsel varlıklarını içerir:

- `logo.png` — EFEAI logosu
- `icons/` — Uygulama ikonları
- `themes/` — Renk temaları

## Temalar

EFEAI terminal uygulaması olduğu için renkli çıktı için ANSI renk kodları kullanılır.
Temalar ilerleyen sürümlerde GUI arayüzü için eklenecektir.
